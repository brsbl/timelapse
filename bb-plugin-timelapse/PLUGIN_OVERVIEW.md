Timelapse turns finished map renders into reviewable, editable media inside BB.

- Frame-level video review with seek, step, and metadata.
- Lightweight trim and caption editing with an overlay preview.
- Exact-frame PNG stills and captioned MP4 exports.
- Matching `bb timelapse` commands and agent tools.

Open a `timelapse` project from a BB thread. Video files stay in the project's `out/` folder; exported media goes to `out/edits/`. The workspace host needs ffmpeg, ffprobe, and ImageMagick. This plugin does not redistribute source datasets.
